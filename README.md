📊 Expense Tracker – React + Vite

A modern and user-friendly Expense & Income Tracker built using React + Vite.
This application allows users to easily manage daily expenses and income, visualize financial activity using real-time charts, and maintain a clean history of transactions.

Designed for performance, simplicity, and a smooth user experience.

⚡ React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Available Plugins:

@vitejs/plugin-react — uses Babel for Fast Refresh

@vitejs/plugin-react-swc — uses SWC for Fast Refresh

React Compiler

The React Compiler is not currently compatible with SWC.
You can track the issue here:
https://github.com/vitejs/vite-plugin-react/issues/428

Expanding ESLint Configuration

For production applications, using TypeScript + type-aware lint rules is recommended.
See the TS template:
https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts
